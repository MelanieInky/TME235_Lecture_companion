# Mechanics of solid — Companion Site

Quarto website scaffold pairing lecture theory with interactive visualizations.

The overarching structure is made of two part:

- Topic specific notes that complement the lecture material (in /lectures/*.qmd). In a lot each of those notes, we add html widgets for interactive visualization of the concept (in /interactives/*md).
- Solution to problem presented in class, with the code (in /problems/*qmd).
