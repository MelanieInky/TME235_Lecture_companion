Large deformations

See the large deformation topic for more!

In the following exercise, we will use the uniaxial example of the book quite a bit. Take a bar of length \(L\) and cross-section area \(A_0\) when underformed. We deform that bar so that the length becomes \(l\) and its cross-section area \(A\). We assume that the bar is incompressible, meaning that its volume will stay constant, that is

\[ V = L A_0 = A l \tag{1}\]

We have defined the engineering strain as

\[ \epsilon = \frac{l-L}{L} = \frac{l}{L} -1 = \lambda -1 \]

where \(\lambda = \dfrac{l}{L}\) is called the uniaxial stretch. We define the true (or logarithmic strain) by integrating infinitesimal strain over the whole deformation

\[ \epsilon_L = \int_{L}^{l} \frac{d\tilde{l}}{\tilde{l}} = \ln(l) - \ln(L) = \ln \left( \frac{l}{L}\right) = \ln(\lambda) \]

In addition, take a normal force evenly applied at the edge of the bar. The normal stress in the bar is then given by the normal force \(F\) divided by its cross-section, that is

\[ \sigma = \frac{F}{A} \tag{2}\]

If we assume small deformation, then \(A \approx A_0\), and we can ignore the fact that the cross-section area of the bar changes, we define the engineering stress as

\[ \sigma_{\text{eng}} = \frac{F}{A_0} \tag{3}\]

Problem 27

NoteProblem 27

Determine for what stretch \(\lambda\) (tension and compression) the difference between the engineering strain \(\epsilon\) and the true strain \(\epsilon_L\) becomes larger than 1%.

Answer: \(\lambda < 0.865\) and \(\lambda > 1.148\).

In problem 27, we are asked when the difference between the logarithmic and engineering strain becomes bigger than \(1/100\), that is when

\[ |\epsilon - \epsilon_L | = |\lambda - 1 - \ln(\lambda)| > \frac{1}{100} \]

We can start by plotting the difference in strain

Code 
import numpy as np
import matplotlib.pyplot as plt
from scipy.optimize import fsolve

lam = np.linspace(0.8, 1.2, 500)

def eps_eng(lam): return lam - 1
def eps_log(lam): return np.log(lam)
def eps_diff(lam): return eps_eng(lam) - eps_log(lam)

alpha = 1/100
def eq(lam):
    return eps_diff(lam)-alpha

fig, ax = plt.subplots(figsize=(5, 4.5), constrained_layout=True)
ax.plot(lam, eps_diff(lam), lw=2, label=r"$\varepsilon_{eng}-\varepsilon_{L}$")
ax.axhline(alpha, ls="--", color="tab:red", lw=1.2)

ax.set_xlabel(r"$\lambda$")
ax.set_ylabel(r"$\varepsilon_{eng}-\varepsilon_{L}$")
ax.set_xlim(lam[0], lam[-1])
ax.set_ylim(bottom=0)
ax.grid(alpha=0.3)
ax.legend(loc="upper center")
plt.show()

We see that there are two points when the difference is becomes greater than \(0.01\). One is around \(\lambda = 0.85\) and one is around \(\lambda = 1.15\). We can use scipy to find more accurate values

roots = fsolve(eq, [0.85, 1.15])

Problem 28

NoteProblem 28

Assume that a material deforms incompressible with a linear relation between true stress and strain, i.e. \(\sigma = G\,\epsilon_L\). If \(G = 80\) MPa and \(\epsilon_L = 0.1\) determine the engineering stress \(\sigma_\text{eng}\).

Answer: \(\sigma_\text{eng} \approx 7.2\) MPa.

In this task, we are asked to compute an engineering stress from a true stress. The bar is incompressible, therefore we can use Equation 3, Equation 2 and Equation 1 to find a formula for the engineering stress.

Problem 29

Calculating the stress

The stress is given by \(\sigma = G (\lambda^2-1)\). We are given \(G\), we just need to compute the stretch of the bar \(\lambda = l/L\). The bar is unstretched at the angle \(\alpha = 45^o\), hence, the horizontal distance of the bar to the wall is given by \(L \cos(\pi/4) = L / \sqrt(2)\).

The length \(l\) can then be calculated using the relation

\[ \cos(\alpha) = \frac{L/\sqrt{2}}{l} = \frac{1}{\sqrt{2} \lambda} \iff \lambda = \frac{1}{\sqrt{2} \cos \alpha} \]

The stress is then

\[ \sigma = G (\lambda^2-1) = G \left(\frac{1}{2\cos^2 \alpha} -1\right) \]

Calculating the force \(P\)

Equilibrium of forces in the vertical direction yields:

\[ \sigma A \sin{\alpha} + P = 0 \]

We already have \(\sigma\), so we need to compute \(A\). Since the bar is incompressible, its volume does not change, that is

\[ A_0 L = A l \iff A = \frac{A_0}{\lambda} \]

And we get

\[ P = - G \left(\frac{1}{2\cos^2 \alpha} -1\right) \sqrt{2} A_0 \cos \alpha \sin \alpha \]

Code 
G = 80 #MPa
A0 = 100 #mm²
def sigma(G,alpha):
    return G*(1/(2*np.cos(alpha,)**2)-1)

alpha_list = np.linspace(-np.pi/4, np.pi/4,200)
plt.plot(alpha_list * 180/np.pi,sigma(G,alpha_list))
plt.grid()
plt.xlabel(r"$\alpha [\deg]$")
plt.ylabel(r"$\sigma$ [MPa]")
Text(0, 0.5, '$\\sigma$ [MPa]')
Code 
def P(G,A0,alpha):
    return - sigma(G,alpha)*np.sqrt(2)*A0*np.cos(alpha)*np.sin(alpha)

plt.plot(alpha_list * 180/np.pi,P(G,A0,alpha_list))
plt.grid()
plt.xlabel(r"$\alpha [\deg]$")
plt.ylabel(r"$P$ [N]")
Text(0, 0.5, '$P$ [N]')

Problem 30

NoteProblem 30

Assume that a material is subjected to the deformation gradient

\[ [F_{ij}] = \begin{pmatrix} 1 & 0.1 & 0 \\ 0 & 1.1 & 0 \\ 0 & 0.2 & 1 \end{pmatrix} \]

Determine \(\boldsymbol{R}\).

Answer:

\[ [R_{ij}] = \begin{pmatrix} 9.9888\mathrm{e}{-01} & 4.7351\mathrm{e}{-02} & -2.2485\mathrm{e}{-03} \\ -4.7351\mathrm{e}{-02} & 9.9438\mathrm{e}{-01} & -9.4703\mathrm{e}{-02} \\ -2.2485\mathrm{e}{-03} & 9.4703\mathrm{e}{-02} & 9.9550\mathrm{e}{-01} \end{pmatrix} \]

The deformation gradient decomposes into a stretch followed by a rotation (right polar decomposition):

\[ \boldsymbol{F} = \boldsymbol{R} \cdot \boldsymbol{U}, \qquad \boldsymbol{R}^\mathsf{T}\cdot\boldsymbol{R} = \boldsymbol{I}, \quad \boldsymbol{U} = \boldsymbol{U}^\mathsf{T} \ \text{positive definite} \]

The right Cauchy–Green deformation tensor is then

\[ \boldsymbol{C} = \boldsymbol{F}^\mathsf{T} \cdot \boldsymbol{F} = \boldsymbol{U}^\mathsf{T} \cdot \boldsymbol{R}^\mathsf{T} \cdot \boldsymbol{R} \cdot \boldsymbol{U} = \boldsymbol{U}^\mathsf{T} \cdot \boldsymbol{U} = \boldsymbol{U}\cdot\boldsymbol{U} \]

Since \(\boldsymbol{C}\) is symmetric, it has a spectral decomposition in its principal directions \(\boldsymbol{N}_\alpha\):

\[ \boldsymbol{C} = \sum_{\alpha=1}^3 \lambda_\alpha^2 \, \boldsymbol{N}_\alpha \otimes \boldsymbol{N}_\alpha \]

and since \(\boldsymbol{C} = \boldsymbol{U}\cdot\boldsymbol{U}\) with \(\boldsymbol{U}\) positive definite (so \(\lambda_\alpha > 0\)), we get

\[ \boldsymbol{U} = \sum_{\alpha=1}^3 \lambda_\alpha \, \boldsymbol{N}_\alpha \otimes \boldsymbol{N}_\alpha \]

The rotation then follows from

\[ \boldsymbol{R} = \boldsymbol{F} \cdot \boldsymbol{U}^{-1}, \qquad \boldsymbol{U}^{-1} = \sum_{\alpha=1}^3 \lambda_\alpha^{-1} \, \boldsymbol{N}_\alpha \otimes \boldsymbol{N}_\alpha \]

Step 1. Computing the Cauchy-Green deformation tensor.

Code 
F = np.array([[1,0.1,0],
              [0,1.1,0],
              [0,0.2,1]])

C = F.transpose() @ F
C
array([[1.  , 0.1 , 0.  ],
       [0.1 , 1.26, 0.2 ],
       [0.  , 0.2 , 1.  ]])

Step 2. Computing the eigenvalues/eigenvectors for \(C\) to get \(U\)

Code 
eigvals, eigvecs = np.linalg.eig(C) #The principal direction vectors are the column of eigvecs

eigvecs = np.real(eigvecs) #Remove the small residual imaginary parts due to numerical errors.
eigvals = np.real(eigvals)
U = np.zeros((3,3))
for alpha in range(3):
    #DOn't forget the square root!
    U += np.sqrt(eigvals[alpha]) * np.outer(eigvecs[:,alpha],eigvecs[:,alpha])

U
array([[ 0.99887576,  0.04735137, -0.00224847],
       [ 0.04735137,  1.11749239,  0.09470274],
       [-0.00224847,  0.09470274,  0.99550306]])

Step 3. \(R = F.U^{-1}\)

Code 
R = F @ np.linalg.inv(U)
R
array([[ 0.99887576,  0.04735137, -0.00224847],
       [-0.04735137,  0.99437882, -0.09470274],
       [-0.00224847,  0.09470274,  0.99550306]])

Bonus step, verifications

\(\boldsymbol{R}\) is a rotation. A rotation has the following properties:

  • \(\boldsymbol{R}\) is orthogonal: \(\boldsymbol{R}^\mathsf{T}\cdot\boldsymbol{R} = \boldsymbol{I}\)
  • \(\det \boldsymbol{R} = 1\)

In addition, we can double check that we get \(\boldsymbol{F} = \boldsymbol{R} \boldsymbol{U}\), and that \(\boldsymbol{U}\) is symmetric.

Code 
# Verifications
I = np.eye(3)
print("F = R.U        :", np.allclose(F, R @ U))
print("U symmetric    :", np.allclose(U, U.T))
print("R^T.R = I      :", np.allclose(R.T @ R, I))
print("det R          :", np.linalg.det(R))
